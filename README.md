# Price List Cleaner

A Python tool that turns a messy price list into a clean spreadsheet.

## What it does
- Fixes spacing and capital letters
- Removes duplicate items
- Skips broken rows and reports them
- Sorts items by name
- Saves a clean CSV that opens in Excel or Google Sheets
- Prints the total value

## Example
Input: "  apple , 3.50", "BANANA,2.1", "Apple , 3.50", "cheese , abc"
Output: Apple 3.5, Banana 2.1 (duplicate and bad rows removed)

## How to run
1. Install Python 3
2. Run: python main.py
